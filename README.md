## 🧭 About Me

I work in **programmatic advertising operations** — the layer that decides which ad
gets served, to whom, and whether it was delivered correctly. Three-plus years of
running campaigns, Deal IDs, and SLA-driven ticket queues taught me one thing very
clearly: almost every problem in ad ops is a **data problem** wearing an
operations costume.

That realisation is why I'm moving into AI/ML engineering. I'm not switching
careers to escape ops — I'm switching to automate and reason about the exact kind
of messy, high-volume data I already handle every day.

- 🏢 **Ad Operations Analyst** at Comcast India Engineering Center, Chennai
- 📊 **3+ years** in programmatic advertising, DSP campaign management, and ad serving
- 🤝 Client-facing work across **FreeWheel** and **Sky**
- 👨‍🏫 Served as an **SME**, mentoring and onboarding new analysts
- 🎓 **B.E. Mechanical Engineering** — PSNA College of Engineering and Technology

## 🚀 Projects

### [SLA Ticket Analytics Tool](https://github.com/HarshaVardhan1111/SLA-Ticket-Analytics-Tool)

An end-to-end analytics pipeline for support ticket data — built because I wanted to
answer questions about SLA breaches that spreadsheets could not answer well.

- `clean_data.py` — ingests raw ticket exports, normalizes columns, handles missing values
- `sql_analysis.py` — loads cleaned data into SQLite and runs analytical queries
- `stats_analysis.py` — descriptive statistics and breach-pattern analysis
- `main.py` — single entry point that runs the full pipeline

**Stack:** Python · Pandas · SQLite · SQL

> More projects coming as I move through machine learning, APIs, and LLM applications.
